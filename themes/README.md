# Themes

The theme guide is [docs/themes.md](../docs/themes.md). Bundled themes:

- `default/`: the modern EV dash (arc gauge, battery ring, mode pills, media card). Reference.
- `segment/`: a seven-segment instrument face, drawn without a font file. Reference.
- `fields/`: a cycling-computer data page with a 2 x 3 grid. Reference.
- `minimal/`: the smallest theme that uses the whole contract.

Validate them with `tools/check-themes.sh`.
